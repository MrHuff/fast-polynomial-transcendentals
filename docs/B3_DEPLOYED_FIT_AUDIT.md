# B3 deployed-fit provenance and verification

The deployed B3 attention path is source-bound to the patched
FlashAttention-4 submodule at commit
`38afdedda24b0bf26e6904d3bed7807c19a6906e`. Its direct piecewise-D3 forward
coefficients and factored-D4 derivative coefficients are defined in
`flash_attn/cute/polynomial_manifest.py`; the packed-BF16 instruction sequence
is generated by `flash_attn/cute/handwritten_spline_ptx.py`.

The original program that selected these coefficients was not retained. In
particular, the repository does not establish its exact weighting, sample set,
or optimizer. `scripts/audit_b3_deployed_fit.py` is therefore a verification
tool, not a reconstructed fitter.

Run the source-bound CPU audit from the repository root:

```bash
mkdir -p results
python scripts/audit_b3_deployed_fit.py \
  --grid-min -6 --grid-max 6 --grid-points 24577 \
  --json-out results/b3-deployed-fit-audit.json
```

The command fails unless the top-level Gitlink, checked-out FA4 revision, and
the two audited source files match the pinned commit. It reads the constants
from that source and emulates one lane of the deployed PTX:

1. round the input score to BF16;
2. select a piece at the BF16 split and clamp in BF16;
3. scale the D3 coefficients by `1/4096`, round them to BF16, and round each
   fused Horner stage once to BF16;
4. apply the nonnegative clamp;
5. evaluate the affine derivative factor with one BF16 fused multiply-add;
6. multiply it by the deployed forward value and round to BF16.

The JSON compares those values with
`sigmoid(score - log(4096))` and `p * (1 - p)`. It reports references at both
the declared grid coordinate and the deployed BF16-rounded input, so input
quantization can be distinguished from polynomial arithmetic. The file embeds
the observed revision, Git blob identifiers, SHA-256 source hashes, exact
constants, grid definition, aggregate errors, and maximum-error locations.

Changing the score interval or density creates a new declared verification
grid. It does not recover or imply the objective used to produce the deployed
coefficients.
